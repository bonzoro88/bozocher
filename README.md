# bozocher_1.0

Лаунчер для автозапуска приложений на C++

## Как пользоваться
1. Запусти bozocher_1.0.exe
2. Выбери "Add app" — вставь путь к .exe
3. Выбери "Run all" — приложения откроются
4. Выбери "Show list" — покажет список

P.S. Если не робят и не создается .txt с путями, создай его сам!
